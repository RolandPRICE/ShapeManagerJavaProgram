ShapeManagerJavaProgram is a simple program that allows you to create four different shapes: a circle, a rectangle, a square, and a triangle. All of these methods have toString() methods for a readable output for the user, a getArea() method for calculating the area of each shape, a getClassName() method that returns the name of the class of the object calling it, and a constructor that takes in custom values for the attribute of each shape.

The program starts out empty, with four buttons at the bottom: Add Circle, Add Square, Add Rectangle, and Add Triangle. Each button adds a new shape object to the program, and then prompts the user to input a custom value for the attributes of each shape. Once that is done, the user can then click the "Show Area" button to get the area of the specific shape shown to the user.
